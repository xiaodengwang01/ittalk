# 学习协作约定

本目录用于具身智能与 GPU 原理学习。学习者熟悉 PyTorch，希望理解原理、少写代码，并逐步形成可展示的小项目。

- 开始学习任务前，阅读本文件、`README.md`、`学习路线.md`、`学习进度.md`，再读取当前主题的已有笔记。以文件中的进度和用户最新要求为准。
- 一次聚焦一个主题。先用具体例子解释，再让学习者预测或作答，最后补充答案和纠错。除非用户要求完整讲义，不要一口气代写全部课程。
- 默认中文，保留必要的英文术语。重点说明输入输出、张量形状、索引、数据流和因果关系。
- 每篇笔记围绕一个核心问题，保留直观解释、图解或手算、自测、易错点及来源。优先修改已有主题文件；需要实际产出时再建子目录，不预建空文件或空目录。
- 用户要求整理、保存或完成一次学习时，把有效内容写回文件，更新入口和进度。普通问答不必逐句存档。只记录用户实际回答中体现的理解，不能把模型生成的笔记记作用户已经掌握。
- 将资料整理、静态代码阅读、CPU 教学模拟、真实设备实验明确标注。未运行就写未运行；性能数值必须有实际测量依据。
- 涉及课程、论文或代码时给出原始链接；关键代码阅读记录版本或提交。公司能力、支持平台和安装方法等会变化的事实，使用时重新核查官方来源。
- 初始工作机为 Apple M4、16 GB 内存。换机后重新检查环境。优先标准库、已有环境和小输入；PyTorch MPS 是否可用要实际检测。CUDA/Triton 课程实验按兼容设备要求安排，不将 CPU/MPS 结果写成 NVIDIA GPU 性能。
- GPU 第一轮只保留路线中的三个小实验。实验先列假设，再查正确性，最后测耗时；记录设备、软件版本、输入规模、数据类型、预热、同步方式和重复次数。
- 所有需要跨机共享的笔记、小型学习代码、图和结果摘要放在本目录内。相对路径连接图片与文档；不依赖聊天附件路径或某台电脑的绝对路径。
- 环境、缓存、模型权重、大型数据和下载的课程整包放在本目录外。公开数据优先记录来源和必要的小样例；不把其他业务材料、邮箱内容或凭据带入学习文件。
- 上传只包含 `docs/`。原工作机在仓库根目录通过已有的 `scripts/git_sync.py` 同步；遵守该机已有上传授权和忽略规则。其他机器默认阅读，不因本文件而获得上传授权。没有该本机脚本时，不假定它会随仓库克隆得到。
- 推送失败如实说明并保留本地成果；不强制推送，不自动处理未知冲突。使用新机器接着编辑前，先核对并获取远端最新版本。
