# 论坛帖子协作约定

本目录用于昇腾和鲲鹏论坛存稿。这里的帖子规则优先于上级针对学习资料的格式要求，不将整理稿记作用户已经完成的实验或学习进度。

## 技能入口

改编、润色、审核帖子，或根据用户修改更新写作偏好时，先读取本机技能：`$CODEX_HOME/skills/forum-post-rewrite/SKILL.md`；未设置 CODEX_HOME 时使用 `~/.codex/skills/forum-post-rewrite/SKILL.md`。即使技能未列在当前聊天中，也先检查此入口。需要分类参考、精选样例观察或站内规范线索时，再按技能读取对应参考文件。

技能只留本机，不随此仓库同步。换机后若入口不存在，明确说明尚未载入技能；已有成稿仍可阅读，必要时按本文件的最低交付约定处理，不声称已应用完整技能。用户确认迁移技能后再另行复制。

## 交付与存放

- 每篇为 UTF-8 `.txt`：第一行最终标题，第二行空白，其余为正文；不加“标题：”“正文：”。
- 正文使用自然段和必要的普通文字小标题、简单编号。无链接、图片、Markdown 标记、引用编号、编辑说明或占位内容。必要的短命令和报错可独占一行，不依赖图片、表格或长代码才能读懂。
- 保留原材料事实和经历归属，允许重新组织。第三方的实验、错误和结果不能改成用户亲历。缺少影响结论的资料时先在聊天中说明，不保存为可直接发布的成稿。
- 原始材料、来源网址、内部核对记录默认留在本目录外的本机位置；必要的来源说明在正文中使用作者、文章名等纯文字。只上传用户打算共享的成稿与目录说明。
- 成稿按论坛分别放在 `昇腾/` 或 `鲲鹏/`，文件名为 `001-简短标题.txt`；编号在各论坛内递增，修改同一篇时沿用编号与原文件。首次有成稿才创建论坛子目录。分类默认记在 `说明.txt`，积累后确有需要再设分类目录，不批量创建空目录。
- 论坛、分类和状态写在 `说明.txt` 的存稿记录中，不混入文章。状态如“待用户复核”“已确认”“已发布”；只有用户明确反馈或实际核实后才记为已发布。格式检查通过不等于事实、个人口吻或发布资格已经确认。
- 成稿和本目录说明按上级约定检查、提交、上传；技能和参考材料不移入 docs。保存、上传到 GitHub 不代表获准向论坛发帖。

完整写作方法只在本机技能维护。用户逐句修改产生的偏好经核对后更新技能；不要把一次删改扩成对所有类别的硬性模板。
